Tienda de barrio en Itagüí. Don Pedro quiere llevar el control de sus productos y de sus clientes.

## Archivos

- `productos.txt`: productos y precios.
- `clientes.txt`: clientes frecuentes.

## Domicilios

- Cobertura: barrio Laureles
